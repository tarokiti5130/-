1. 機能一覧

機能概要操作する画面
データの登録単語名・説明・タグを入力して保存するデータ登録・編集
データの閲覧一覧と詳細で登録内容を確認するホーム／図鑑一覧、データ詳細
データの編集登録済みの単語名・説明・タグを変更するデータ登録・編集
データの削除確認のうえ、単語と説明を削除するデータ詳細、削除確認
検索単語名・説明・タグで一覧を絞り込むホーム／図鑑一覧
タグの管理タグ名の変更、タグの削除タグ一覧、削除確認
問題作成機能との連携登録した説明を問題作成に利用できる－

2. 各機能の振る舞い

2.1 データの登録

きっかけホームの「新規登録」から入力画面を開き、「保存」する
入力ルール単語名は必須・100文字以内
説明は複数登録でき、1件以上必須
タグは複数付けられ、1つ50文字以内
保存したとき入力内容を、単語・説明・タグとして登録する
タグの扱い入力したタグが未登録なら、新しいタグとして作る
既にある名前なら、そのタグを使う
同じタグを二重に入力したら、1つにまとめる
入力エラーのときエラーメッセージを表示し、何も保存しない
途中で失敗したとき一部だけが保存された状態にはしない（全部保存するか、全部保存しない）
キャンセル何も保存されない

2.2 データの閲覧

一覧登録されている単語を一覧にし、単語名と付いているタグを表示する
登録が0件のときは、まだ登録がないことを伝える
詳細1つの単語の名前・説明（複数）・タグを表示する

2.3 データの編集

きっかけデータ詳細の「編集」
開いたとき現在の単語名・説明・タグが入った状態で開く
変更できること単語名の変更、説明の追加・変更・削除、タグの付け外し・新しいタグの作成
入力ルール登録と同じ（単語名は必須・100文字以内、説明は1件以上、タグは1つ50文字以内）
保存したとき変更を反映する。外した説明は削除される
外したタグは、その単語から外れるだけで、タグそのものは残る
キャンセル変更を捨てて、元の内容のままにする

2.4 データの削除

きっかけデータ詳細の「削除」
確認削除する単語名と、説明も一緒に消えることを伝える
削除したとき単語とその説明を削除し、その単語に付いていたタグとの関連も外す
タグそのものは残る（ほかの単語に付いていなくても、タグ一覧に残る）
キャンセル何も削除しない
元に戻す削除したデータは元に戻せない

2.5 検索

場所ホームの検索欄から行い、同じ一覧の中で絞り込む
検索の対象単語名、説明、タグ名
一致のしかた部分一致。複数の語を入れたときは、すべて含むものを探す（AND）
検索欄が空のとき全件を表示する
該当がないとき該当なしと分かる表示を出す

2.6 タグの管理

一覧の表示タグ名と、そのタグが付いている単語の数を表示する
名前の変更タグ名をその場で変更する
空の名前、50文字を超える名前、既にあるタグ名には変更できない
変更後は、そのタグが付いているすべての単語に新しい名前で表示される
削除「×」を押すと確認を出し、削除する
タグが消え、付いていた単語からタグだけが外れる。単語は残る
確認メッセージに、外れる単語の件数を出す
新しいタグの作り方タグ一覧からは作らない。登録・編集でタグを入力したときに作る

3. 共通の決まり

項目内容
入力エラーのときエラーメッセージを表示し、保存や変更は行わない
削除の前の確認データ・タグのどちらの削除も、確認を経てから実行する
保存先利用者のパソコン内。ネットワークなしで使える

4. 問題作成機能との連携(未定)

図鑑に登録した情報のうち、1つの単語に登録された複数の説明を、問題作成機能が利用できる。問題の作成方法や出題形式は、問題作成機能の仕様に従う。
